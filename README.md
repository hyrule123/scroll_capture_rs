# scroll_capture_rs

화면의 원하는 영역을 **자동으로 스크롤하면서 캡처**하고, 결과를 이어 붙여 **긴 이미지 한 장**으로 만드는 Windows 프로그램입니다.

Rust로 작성했고, 런타임 설치 없이 **exe 파일 하나**로 실행됩니다.

## 주요 기능

- **드래그로 영역 선택**: 화면을 어둡게 덮은 오버레이에서 스크롤할 부분만 드래그로 고릅니다.
- **자동 스크롤 캡처**: 마우스 휠로 스크롤하면서 화면을 찍고, 겹치는 부분을 찾아 자연스럽게 이어 붙입니다.
- **하단 고정 영역 처리**: 스크롤해도 움직이지 않는 아래쪽 영역(가로 스크롤바, 고정 배너, 상태 표시줄 등)을 찾아서 결과의 맨 아래에 한 번만 붙입니다.
- **끝 자동 감지**: 더 이상 스크롤되지 않으면 스스로 멈춥니다.
- **즉시 중단**: 캡처 중 **Esc** 또는 **마우스 클릭(왼쪽/오른쪽)** 으로 바로 멈추고, 그때까지 찍은 부분을 결과로 남깁니다.
- **미리보기, 저장, 복사**: 결과를 바로 확인하고 PNG로 저장하거나 클립보드에 복사합니다.
- **메인 창이 찍히지 않음**: 프로그램 창은 화면 캡처에서 제외되도록 설정되어 있습니다.

## 사용법

1. 캡처할 프로그램(웹페이지, 문서 등)을 띄워 둡니다.
2. `scroll_capture_rs.exe`를 실행하고 필요하면 설정을 바꿉니다.
3. **스크롤 캡처 시작**을 누릅니다.
4. 화면이 어두워지면 **스크롤할 영역을 드래그**합니다. (Esc 또는 오른쪽 클릭: 취소)
5. 메인 창이 최소화되고 자동으로 스크롤하며 캡처합니다. (Esc 또는 마우스 클릭: 중단)
6. 끝나면 창이 다시 나타납니다. 미리보기를 확인하고 **PNG로 저장** 또는 **클립보드에 복사**를 누릅니다.

### 설정

| 항목 | 기본값 | 설명 |
|---|---|---|
| 스크롤 대기 (ms) | 500 | 휠을 굴린 뒤 화면이 멈출 때까지 기다리는 시간. 부드러운 스크롤이나 느리게 그려지는 프로그램은 늘려 주세요. |
| 최대 높이 (px) | 20000 | 결과 이미지가 이 높이를 넘으면 멈춥니다. 끝없이 내용이 이어지는 페이지 대비용입니다. |
| 휠 칸 수 | 1 | 한 번에 굴릴 휠 칸 수. 늘리면 빨라지지만 겹치는 부분이 줄어 이어 붙이기가 불안정해질 수 있습니다. |

### 잘 찍기 위한 팁

- **스크롤되는 부분만** 선택하세요. 휠은 선택 영역의 **가운데**에서 굴러갑니다. 가운데에 다른 스크롤 영역(코드 블록, 표 등)이 걸리면 그쪽이 스크롤됩니다.
- 마우스를 올리면 강조 표시가 생기는(hover) 프로그램은 결과가 흔들릴 수 있습니다. 이럴 때는 **영역을 세로로 크게** 잡으면 안정적입니다.
- 캡처 중에는 마우스와 키보드를 건드리지 마세요. 클릭하면 중단됩니다.

## 요구 사항

- Windows 10 (버전 2004 이상) / Windows 11
  - 이전 버전에서도 실행은 되지만, 오버레이 스크린샷에 메인 창이 찍힐 수 있습니다.
- 그래픽 드라이버가 설치된 환경 (GPU 렌더링 사용)
- Windows 설정의 **"비활성 창 위에 마우스를 올려 놓을 때 스크롤"** 이 켜져 있어야 합니다. (기본값: 켜짐)

## 빌드

[Rust](https://rustup.rs)와 Visual Studio Build Tools(C++를 사용한 데스크톱 개발)가 필요합니다.

```bash
cargo build --release
```

결과물: `target\release\scroll_capture_rs.exe`

- C 런타임을 정적으로 포함하므로(`.cargo/config.toml`) Visual C++ 재배포 패키지 없이 실행됩니다.
- 릴리스 빌드는 콘솔 창 없이 실행됩니다. 개발 중(`cargo run`)에는 콘솔에 진행 로그가 출력됩니다.

알고리즘 테스트:

```bash
cargo test
```

## 동작 원리

1. **행 해시**: 캡처한 화면의 각 행(가로 한 줄)을 FNV-1a 해시 하나로 요약합니다. 한 가지 색으로만 된 행(빈 줄)은 따로 표시해서 비교에서 빼고, 오른쪽 스크롤바 영역은 해시에서 제외합니다.
2. **이동량 찾기**: 스크롤 전 화면(`prev`)과 후 화면(`cur`)을 한 줄씩 어긋나게 맞춰 보면서(`cur[i] == prev[i + dy]`), 가장 많은 행이 일치하는 `dy`를 찾습니다. 일치 비율이 60% 미만이면 후보에서 뺍니다. 그래서 상단 고정 헤더처럼 일부 행이 어긋나도 위치를 찾을 수 있습니다.
3. **고정 영역 감지**: 아래쪽부터 같은 행 번호끼리 비교해서, 스크롤했는데도 그대로인 영역을 하단 고정 영역으로 봅니다.
4. **이어 붙이기**: 스크롤할 때마다 본문의 맨 아래 `dy`줄(새로 드러난 부분)만 결과 버퍼 뒤에 덧붙입니다. 끝나면 고정 영역을 한 번 붙입니다.

## 프로젝트 구조

```
src/
├─ main.rs       진입점
├─ gui.rs        메인 창, 영역 선택 오버레이, 진행 표시, 미리보기, 저장/복사 (egui)
├─ capture.rs    스크롤 → 캡처 → 이어 붙이기 루프, 중단 입력 확인
└─ analyzer.rs   행 해시, 스크롤 이동량, 하단 고정 영역 감지 (+ 단위 테스트)
```

## 알려진 제한

- 세로 스크롤만 지원합니다.
- 마우스 휠에 반응하지 않는 프로그램은 스크롤되지 않습니다.
- 동영상이나 움직이는 광고처럼 계속 바뀌는 요소가 크게 들어가면 이어 붙이기에 실패할 수 있습니다.
- 스크롤 위치에 따라 모양이 바뀌는 상단 고정 헤더는 결과에 그대로 남을 수 있습니다.
- 캡처하는 모니터는 메인 창이 있는 모니터입니다.
